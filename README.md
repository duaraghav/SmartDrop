# SmartDrop

Mobile sign-in and onboarding flow for SmartDrop, built in [Figma Make](https://www.figma.com/make/SZvV2AqJEGQcnrE78VDT77/Mobile-Sign-In-Onboarding-Flow).

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4

## Run locally

```bash
pnpm install
pnpm dev
```

Build for production with `pnpm build` (output in `dist/`).
